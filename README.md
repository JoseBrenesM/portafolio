# Portafolio de José Brenes

Portafolio personal bilingüe creado con React y Vite. Incluye proyectos, experiencia, formación y una interfaz adaptable a dispositivos móviles.

## Desarrollo local

Se requiere Node.js 24.

```sh
npm install
npm run dev
```

## Comprobaciones

```sh
npm run lint
npm run build
```

La carpeta `dist` contiene la versión de producción generada por Vite y se crea al ejecutar `npm run build`.
